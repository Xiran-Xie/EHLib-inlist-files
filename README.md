# EHLib inlist files (arXiv: 2507.15044)
MESA inlist files for the asteroseismic modeling of EH Lib (see arXiv:2507.15044)

This repository contains the MESA `inlist` files and setup configurations used for the asteroseismic study of the high-amplitude $\delta$ Scuti star **EH Lib**.

## Software Versions
*   **MESA**: r22.11.1
*   **GYRE**: v6.0
